# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful and constructive in issues and anywhere else you interact with this project. Harassment, personal attacks and spam are not tolerated.

To report unacceptable behavior, use **Report content** in the menu of the issue or comment, which reaches the maintainer. You can also [report abuse to GitHub](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

The maintainer may edit, hide or delete comments, lock conversations, and block accounts that break this code of conduct.
